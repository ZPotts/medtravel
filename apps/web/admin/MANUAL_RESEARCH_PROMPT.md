# Manual research prompt

The research prompt is not kept in this file. It is generated by the admin page, which holds the single source of the prompt text.

- **Prompt source:** the `TEMPLATE` constant in [index.html](index.html)
- **How to use it:** see [Research Guide, Paste workflow](../../../docs/RESEARCH_SCRIPT_GUIDE.md#paste-workflow)

To change the prompt, edit `TEMPLATE` in `index.html`. Do not paste a copy here, because copies drift out of sync.
