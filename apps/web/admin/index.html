Research prompt builder

Enter a city and a service. Copy the prompt into any web-browsing AI agent (Claude, ChatGPT, Gemini, Perplexity…) and it returns structured clinic data as JSON.

Mode
  1. Paste into an AI agent that can browse the web.
  2. Copy the JSON array it returns.
  3. Save it as research_results/<city>_<service>_<date>.json.

Check results

Paste the JSON the agent returned to view it as a table. Click a column header to sort.
